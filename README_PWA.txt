# English With Alex — PWA

Stable baseline: Academy Pro + Ivorian Study Map, wrapped as an installable Progressive Web App.

Files:
- index.html — stable website
- manifest.json — app metadata
- service-worker.js — offline/cache support
- icons/icon.svg — app icon

Deploy these files at the same GitHub Pages root. Open the site in Chrome on Android, then use the browser menu and choose Install app / Add to Home screen when offered.
